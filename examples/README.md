# ASCII Wireframe Examples

This directory contains reference examples of ASCII wireframes for common UI patterns.

## Examples

- **01-login-form.txt** - Simple authentication form with social login options
- **02-dashboard.txt** - Admin dashboard with metrics cards and activity feed
- **03-blog-post.txt** - Blog post layout with comments section

## Usage

These examples demonstrate the patterns defined in the [specification](../spec/v0.1-draft.md). Use them as:

1. **Learning references** - See how common patterns are represented
2. **Starting templates** - Copy and modify for your own designs
3. **Testing data** - Validate tools against known good examples

## Contributing Examples

When adding new examples:

- Use clear, descriptive filenames
- Include a variety of UI elements
- Keep examples focused on one main pattern
- Add entry to this README
- Ensure they follow the latest spec

## Real-World Usage

These wireframes are meant to be shared with AI coding assistants like Claude Code. For example:

```
Create a React component based on this wireframe:

[paste wireframe here]
```

The AI assistant will understand the structure and create appropriate code.
