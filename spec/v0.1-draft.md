# ASCII Wireframes Specification v0.1 (DRAFT)

**Status**: Early Draft
**Last Updated**: 2025-10-26

## Abstract

This document defines ASCII wireframes as a human-readable, plain-text format for communicating user interface designs to AI coding assistants and human developers.

## Goals

- Provide a consistent, unambiguous way to describe UI layouts
- Enable rapid iteration on interface design
- Work seamlessly with version control systems
- Be easy to write without special tools
- Be immediately understandable by both humans and AI

## Core Concepts

### 1. Box Drawing

ASCII wireframes use box-drawing characters to represent visual boundaries and structure:

```
Basic box:
┌─────────┐
│ Content │
└─────────┘

Nested structure:
┌─────────────────────┐
│ Header              │
├─────────────────────┤
│ ┌─────┐  ┌─────┐   │
│ │ Box │  │ Box │   │
│ └─────┘  └─────┘   │
└─────────────────────┘
```

**Box-drawing characters**:
- `┌ ┐ └ ┘` - corners
- `─ │` - horizontal and vertical lines
- `├ ┤ ┬ ┴ ┼` - connections

**HTML Translation:**

```html
<!-- Basic box using <div> with border -->
<div style="border: 1px solid black; padding: 8px;">
  Content
</div>

<!-- Nested structure -->
<div style="border: 1px solid black;">
  <div style="padding: 8px; border-bottom: 1px solid black;">
    Header
  </div>
  <div style="padding: 8px; display: flex; gap: 8px;">
    <div style="border: 1px solid black; padding: 8px;">Box</div>
    <div style="border: 1px solid black; padding: 8px;">Box</div>
  </div>
</div>
```

**Minimal CSS (optional):**
```css
/* If you want to avoid inline styles */
.box { border: 1px solid black; padding: 8px; }
.box-header { border-bottom: 1px solid black; padding: 8px; }
```

### 2. Interactive Elements

Common UI components are represented with brackets and symbols:

```
Buttons:    [ Submit ]  [ Cancel ]
Input:      [____________]  or  [ Enter text...    ]
Checkbox:   [ ] Unchecked    [x] Checked
Radio:      ( ) Unselected   (•) Selected
Dropdown:   [ Select...  ▾ ]
Link:       → Learn More  or  Learn More →
Icon:       [🔍] or [≡] or [⚙]
```

**HTML Translation:**

```html
<!-- Buttons -->
<button style="border: 1px solid black; padding: 4px 12px; background: white;">
  Submit
</button>
<button style="border: 1px solid black; padding: 4px 12px; background: white;">
  Cancel
</button>

<!-- Input field -->
<input type="text" placeholder="Enter text..."
       style="border: 1px solid black; padding: 4px;">

<!-- Checkbox -->
<label>
  <input type="checkbox"> Unchecked
</label>
<label>
  <input type="checkbox" checked> Checked
</label>

<!-- Radio button -->
<label>
  <input type="radio" name="choice"> Unselected
</label>
<label>
  <input type="radio" name="choice" checked> Selected
</label>

<!-- Dropdown -->
<select style="border: 1px solid black; padding: 4px;">
  <option>Select...</option>
</select>

<!-- Link -->
<a href="#" style="color: black; text-decoration: underline;">
  → Learn More
</a>

<!-- Icon (using text or Unicode) -->
<span style="border: 1px solid black; padding: 2px 6px;">🔍</span>
<span style="border: 1px solid black; padding: 2px 6px;">≡</span>
<span style="border: 1px solid black; padding: 2px 6px;">⚙</span>
```

### 3. Lists and Grids

Represent collections of items consistently:

```
Simple list:
- Item 1
- Item 2
- Item 3

Card grid:
┌─────────┐  ┌─────────┐  ┌─────────┐
│ Card 1  │  │ Card 2  │  │ Card 3  │
│         │  │         │  │         │
└─────────┘  └─────────┘  └─────────┘
```

**HTML Translation:**

```html
<!-- Simple list -->
<ul style="list-style: disc; padding-left: 20px;">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

<!-- Card grid -->
<div style="display: flex; gap: 8px;">
  <div style="border: 1px solid black; padding: 16px; flex: 1;">
    Card 1
  </div>
  <div style="border: 1px solid black; padding: 16px; flex: 1;">
    Card 2
  </div>
  <div style="border: 1px solid black; padding: 16px; flex: 1;">
    Card 3
  </div>
</div>
```

### 4. Text Hierarchy

Use spacing and formatting to indicate importance:

```
# Large Heading

## Medium Heading

Regular body text

[Primary Action]  [Secondary Action]
```

**HTML Translation:**

```html
<!-- Large heading -->
<h1 style="font-size: 2em; font-weight: bold; margin: 0.67em 0;">
  Large Heading
</h1>

<!-- Medium heading -->
<h2 style="font-size: 1.5em; font-weight: bold; margin: 0.75em 0;">
  Medium Heading
</h2>

<!-- Regular body text -->
<p style="margin: 1em 0;">
  Regular body text
</p>

<!-- Actions -->
<button style="border: 2px solid black; padding: 8px 16px; background: white; font-weight: bold;">
  Primary Action
</button>
<button style="border: 1px solid black; padding: 8px 16px; background: white;">
  Secondary Action
</button>
```

### 5. Layout and Spacing

Indentation indicates hierarchy and grouping:

```
┌─────────────────────────────┐
│ App                         │
├─────────────────────────────┤
│                             │
│  Main Content Area          │
│                             │
│  ┌──────────────────────┐   │
│  │ Nested Component     │   │
│  │                      │   │
│  │  Further nested      │   │
│  └──────────────────────┘   │
│                             │
└─────────────────────────────┘
```

**HTML Translation:**

```html
<div style="border: 1px solid black;">
  <!-- Header -->
  <div style="padding: 8px; border-bottom: 1px solid black;">
    App
  </div>

  <!-- Main content area -->
  <div style="padding: 16px;">
    Main Content Area

    <!-- Nested component -->
    <div style="border: 1px solid black; padding: 16px; margin-top: 16px;">
      Nested Component

      <div style="padding: 8px;">
        Further nested
      </div>
    </div>
  </div>
</div>
```

## Common Patterns

### Navigation Header

```
┌─────────────────────────────────────┐
│ Logo        Home  About  Contact [≡]│
└─────────────────────────────────────┘
```

**HTML Translation:**

```html
<header style="border: 1px solid black; padding: 12px; display: flex; justify-content: space-between; align-items: center;">
  <strong>Logo</strong>
  <nav style="display: flex; gap: 16px;">
    <a href="#" style="color: black; text-decoration: none;">Home</a>
    <a href="#" style="color: black; text-decoration: none;">About</a>
    <a href="#" style="color: black; text-decoration: none;">Contact</a>
  </nav>
  <button style="border: 1px solid black; padding: 4px 8px; background: white;">≡</button>
</header>
```

### Form Layout

```
┌─────────────────────────────────────┐
│ Contact Form                        │
├─────────────────────────────────────┤
│                                     │
│  Name: [____________________]       │
│                                     │
│  Email: [____________________]      │
│                                     │
│  Message:                           │
│  [_______________________________]  │
│  [_______________________________]  │
│  [_______________________________]  │
│                                     │
│  [ ] Subscribe to newsletter        │
│                                     │
│  [ Submit ]         [ Cancel ]      │
│                                     │
└─────────────────────────────────────┘
```

**HTML Translation:**

```html
<form style="border: 1px solid black;">
  <!-- Header -->
  <div style="padding: 12px; border-bottom: 1px solid black;">
    <strong>Contact Form</strong>
  </div>

  <!-- Form body -->
  <div style="padding: 16px;">
    <div style="margin-bottom: 16px;">
      <label style="display: block; margin-bottom: 4px;">Name:</label>
      <input type="text" style="border: 1px solid black; padding: 4px; width: 100%; max-width: 300px;">
    </div>

    <div style="margin-bottom: 16px;">
      <label style="display: block; margin-bottom: 4px;">Email:</label>
      <input type="email" style="border: 1px solid black; padding: 4px; width: 100%; max-width: 300px;">
    </div>

    <div style="margin-bottom: 16px;">
      <label style="display: block; margin-bottom: 4px;">Message:</label>
      <textarea rows="4" style="border: 1px solid black; padding: 4px; width: 100%; max-width: 500px;"></textarea>
    </div>

    <div style="margin-bottom: 16px;">
      <label>
        <input type="checkbox"> Subscribe to newsletter
      </label>
    </div>

    <div style="display: flex; gap: 8px;">
      <button type="submit" style="border: 1px solid black; padding: 6px 16px; background: white;">Submit</button>
      <button type="button" style="border: 1px solid black; padding: 6px 16px; background: white;">Cancel</button>
    </div>
  </div>
</form>
```

## Annotations

Use comments to provide additional context:

```
┌─────────────────────────────────────┐
│ Dashboard                      [≡]  │
├─────────────────────────────────────┤
│                                     │
│  // User profile section            │
│  ┌──────────────────────────────┐   │
│  │ @username             [Edit] │   │
│  └──────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

## Best Practices

1. **Be Consistent**: Use the same characters for the same elements throughout
2. **Add Context**: Include labels and annotations where helpful
3. **Show State**: Indicate interactive states (selected, disabled, etc.)
4. **Keep it Simple**: Focus on structure over pixel-perfect representation
5. **Consider Responsive**: Note breakpoints or layout variations when relevant
